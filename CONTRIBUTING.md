# Contributing

This is a small reference project for discussing Laravel architecture and engineering trade-offs.

Before opening a change:

1. Explain the problem and the boundary being changed.
2. Add or update a feature/unit test for behaviour changes.
3. Run `php artisan test` and `vendor/bin/pint --test` locally.
4. Keep examples synthetic; never add credentials, customer data, or proprietary employer material.

Pull requests should describe whether the change affects functionality, documentation, or local developer experience.
